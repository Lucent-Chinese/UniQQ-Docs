# UI 规范

这个是UniQQ UI 相关的设计规范。插件开发者无需关注。

---

## 概述

UniQQ 插件运行在桌面端（WinForms）环境中，可以直接使用 `System.Windows.Forms`不需要using！ 或 WPF 创建配置界面。

由于插件是**类库项目**（非 EXE），没有内置的资源管理和设计器支持。建议：

1. **手写控件代码**而非依赖 Visual Studio 设计器
2. **保持 UI 简洁**——插件的设置界面通常只需要几个配置项
3. **使用 `ShowDialog()` 模态显示**

> 直接导入的Designer设计界面可能会出现很多不可预料的错误

---

## 窗口设计规范

### 基本要求
#### 可关闭！确保有关闭按钮或取消按钮！
#### 线程安全！所有 UI 操作在主线程执行！

---

## 配色建议

你可以选择与 UniQQ 客户端风格一致，建议：
- 主题色 #7650FC
- 按钮(悬浮) #987BFD
- 按钮(禁用) #F0EEF9
- 背景色 #FFFFFF
- 有色背景 #E5E2F2
